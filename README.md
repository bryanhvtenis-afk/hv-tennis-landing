# HV Tennis Academy — Landing

Página de captación para clases privadas de tenis a domicilio en Quito y Cumbayá.
Entrenador ITF Nivel 2. Servicio ancla: **Radiografía del Swing** (análisis de técnica en video).

## Editar el número de WhatsApp

En `index.html`, busca la línea marcada con `CAMBIA SOLO ESTA LÍNEA` y reemplaza
`593XXXXXXXXX` por el número real con código de país, sin `+` ni espacios.

## Publicación

Sitio estático servido por GitHub Pages desde la rama `main`, carpeta raíz.
Cualquier cambio en `index.html` que llegue a `main` se publica solo en 1–2 minutos.
